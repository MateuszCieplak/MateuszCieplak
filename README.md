## Featured project

### [Mafia IRL](https://github.com/MateuszCieplak/mafia-irl-app)

A mobile-first web app for playing Mafia around a real table. Everyone joins from their phone, the host runs the night and day phases, and roles, night actions and votes stay in sync in real time.

- Game engine on the server (Express + Socket.IO): phase flow, night resolution, day voting, win conditions, reconnect handling, optional phase timers, and bots for playtesting
- Accounts and data in PocketBase, with a Next.js 14 + Tailwind front end
- Vitest suite covering every phase, plus a full-game integration test
- Dockerfiles for web and server, and a one-command LAN setup for testing on real phones

`Next.js` `React` `Tailwind CSS` `Node.js` `Express` `Socket.IO` `PocketBase` `Vitest` `Docker`
